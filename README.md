## 🎮 Big Tiny Heroes

A live 3D browser MMORPG with a server-authoritative real-time multiplayer backend. My work there includes:

- Gameplay systems: stamina, death and revive, mob combat effects, quest tracker
- Physics and collision with Rapier 3D
- Custom GLSL shaders in Three.js (animated cloth for flags and banners)
- Spatial audio system with zones and crossfades
- Tested procedural map generators
- Admin moderation tools and in-game bug reports to GitHub Issues

**Stack:** TypeScript · React 19 · Three.js · Rapier · Node.js · Fastify · Colyseus · Redis · SQLite · Docker · Playwright

👉 Play it at [bigtinyheroes.com](https://bigtinyheroes.com)
